# Number Guessing Game

## Description

A Java console application where the computer generates a random number between 1 and 100. The player tries to guess the number within a limited number of attempts.

---

## Features

- Random Number Generation
- User Input
- Too High / Too Low Hints
- Limited Attempts
- Multiple Rounds
- Score System
- Final Score Display

---

## Technologies Used

- Java
- Random Class
- Scanner Class
- Loops
- Conditional Statements

---

## How to Run

Compile

javac NumberGame.java

Run

java NumberGame
